An entry for the [make.fun](https://make.fun/c/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9) competition **"The Meeting That Should Have Been an Email"**: write one line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny.

## What the program does

`main.ts` scores a small set of original candidate one-liners against the judge's own brief — on-topic, the laugh, surprise, economy, recognition — and writes the best one to `/output/entry.txt`. Fully deterministic: no clock, no network, no randomness, so every run writes the same bytes.

## Run it

```sh
node main.ts
```

Node 22.18 or later. It writes `/output/entry.txt` (one line, no trailing newline).

## The winning line

> We spent an hour in a meeting reading an email out loud to the twelve people who wrote it.
